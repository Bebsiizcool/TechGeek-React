# TechGeek 

TechGeek is a modern, animated frontend project built with **React, Vite, and Tailwind CSS**. I created this project to practice and strengthen my React and frontend development skills while experimenting with reusable components, animations, responsive UI, and interactive effects.

The current version is **frontend-only**, but this project is being developed with the goal of evolving it into a **full-stack MERN application** as I continue learning backend development.

##  Current Tech Stack

* **React** — Component-based UI development
* **Vite** — Fast development environment and build tool
* **Tailwind CSS** — Responsive and utility-first styling
* **AOS (Animate On Scroll)** — Scroll-triggered animations
* **React Icons** — Icons throughout the interface
* **Canvas** — Custom animated visual effects
* **Oxlint** — Code linting

##  Current Features

* Modern animated landing page
* Reusable React components
* Scroll-triggered animations
* Custom canvas-based shooting star effect
* Interactive hover effects
* Responsive UI development with Tailwind CSS
* Component-based page sections
* Deployed frontend

## 🛠️ Planned Development

TechGeek is also part of my journey toward becoming a **MERN Stack Developer**.

Future development will include:

* **Node.js + Express.js** backend
* **MongoDB** database
* **Mongoose** for database management
* REST API integration
* Dynamic content
* User authentication
* Full-stack functionality
* Full MERN deployment

The goal is to gradually transform the current frontend into a functional full-stack application while learning and implementing each part of the MERN stack.

##  Purpose

This project is primarily a **learning and practice project**. I wrote the code myself while applying the React concepts I've been learning, rather than relying on AI-generated code.

It serves as a place for me to experiment with React architecture, UI development, animations, component reusability, and eventually backend integration as I progress toward full-stack development.
